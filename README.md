# AI Chatbot Online and Offline

This project is an AI chatbot designed to work in both online and offline modes. In online mode, it can connect to internet-based AI services or APIs for advanced responses. In offline mode, it can provide basic chatbot responses without requiring an internet connection.

## Features
- Works in online and offline modes
- Provides AI-based chatbot responses
- Supports internet-based response generation
- Allows basic offline interaction
- Simple and user-friendly chatbot interface

## Purpose
The purpose of this project is to create a flexible chatbot system that can assist users even when internet access is unavailable.
